Edith

A friendly text editor for the terminal.

Pull-down menus, dialogs and the mouse, like the classic MS-DOS EDIT – with split windows and tabs, syntax highlighting for more than 50 languages, code formatting and an optional, faithful Vim mode. One program, nothing to configure.

Features

Everything is in the menus – press F10 or Alt – and every menu entry shows its shortcut. F1 lists all keys.

Menus and dialogs

Open the menus with Alt+letter or the mouse. The status line explains the selected entry, check marks show the options that are on.

  • the usual keys: Ctrl+S Ctrl+Z Ctrl+F Ctrl+C Ctrl+V
  • selecting with Shift and the mouse
  • the system clipboard, also over SSH

Split windows and tabs

Split the screen side by side or above each other, show the same file in several windows with their own cursors, and keep more files in tabs.

  • F6 next window, Ctrl+W closes one
  • Ctrl+T new tab, F4 closes it, Ctrl+PgDn / Ctrl+PgUp switch
  • drag the borders with the mouse

Highlighting with tree-sitter

More than 50 languages are fully parsed, including languages embedded in others: code blocks in Markdown, JavaScript and CSS in HTML, HTML in PHP, regular expressions in JavaScript.

  • C, C++, C#, Go, Rust, Java, Kotlin, Swift, Python, Ruby, PHP, JavaScript, TypeScript …
  • HTML, CSS, JSON, YAML, TOML, Markdown, SQL, Shell, Dockerfile, Makefile …

Find, replace, reformat

Find and replace with or without confirmation. F8 formats the file with the standard formatter of its language – clang-format, ruff, gofmt, rustfmt, prettier and others – or re-indents it along the syntax tree when none is installed.

Vim mode

Options > Vim Mode (F12, or edith --vim) turns on Vim's key bindings – and they behave like Vim, down to the edge cases.

  • Normal, Insert, Replace and all three Visual modes
  • operators, motions, text objects, counts and .
  • registers, macros, marks, the jump list
  • Vim's regular expressions, :s, :g, :sort, :normal, :map
  • windows and tabs with Ctrl-W, :split, :tabnew

The menus stay one Alt away.

Install

Ready-made packages for Linux on x86_64 and for macOS on Apple Silicon. The command is edith.

Arch · CachyOS · Manjaro

The package edith-editor:

$ curl -LO https://github.com/dlehmann/edith/releases/latest/download/edith-editor-x86_64.pkg.tar.zst
$ sudo pacman -U edith-editor-x86_64.pkg.tar.zst

Debian · Ubuntu · Mint

The package edith:

$ curl -LO https://github.com/dlehmann/edith/releases/latest/download/edith_amd64.deb
$ sudo apt install ./edith_amd64.deb

macOS · Apple Silicon

Not notarized by Apple: download it with curl, not with a browser.

$ curl -LO https://github.com/dlehmann/edith/releases/latest/download/edith-macos-arm64.tar.gz
$ tar -xzf edith-macos-arm64.tar.gz
$ sudo mkdir -p /usr/local/bin && sudo install -m755 edith-*-macos-arm64/edith /usr/local/bin/

Any Linux

An AppImage and a static binary are on the release page.

$ chmod +x Edith-*.AppImage
$ ./Edith-*.AppImage file.txt

From source

Needs a C++17 compiler, make, git and curl.

$ git clone https://github.com/dlehmann/edith.git && cd edith
$ tools/fetch-grammars.sh && make -j$(nproc)
$ make install

About

Edith runs in every terminal that speaks UTF-8 – xterm, GNOME Terminal, Konsole, kitty, Alacritty, WezTerm, foot, tmux, the Linux console – and with every shell.

One programAll grammars are compiled in. No plugins, no configuration needed.
Safe savingA file is replaced only after the new text was written completely. Encoding, line endings and permissions are kept.
FastIncremental parsing, only the visible lines are highlighted, only changed cells are redrawn.
